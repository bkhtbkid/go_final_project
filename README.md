# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

# Планировщик задач (Go Final Project)

Веб-сервер планировщика задач — итоговый проект курса по Go. Позволяет создавать,
редактировать, удалять и отмечать выполненными задачи, в том числе периодические
(с правилами повторения). Фронтенд встроен в бинарник, данные хранятся в SQLite.

## Возможности

- Добавление, редактирование, удаление задач через REST API
- Периодические задачи с правилами повторения (`d`, `y`, `w`, `m`)
- Отметка задачи выполненной с автоматическим переносом на следующую дату
- Поиск задач по тексту и по дате
- Аутентификация по паролю через JWT

## Выполненные задания со звёздочкой

- Поддержка всех правил повторения, включая `w` (дни недели) и `m` (дни месяца)
- Поиск задач: по подстроке в заголовке/комментарии и по конкретной дате
- Аутентификация по паролю с использованием JWT-токена
- Сборка и запуск проекта через Docker

## Стек

- Go
- SQLite (`modernc.org/sqlite` — чистый Go, без CGO)
- JWT (`github.com/golang-jwt/jwt/v5`)

## Запуск локально

1. Создайте файл `.env` в корне проекта:

```
TODO_PORT=7540
TODO_DBFILE=scheduler.db
TODO_PASSWORD=12345
```

- `TODO_PORT` — порт веб-сервера
- `TODO_DBFILE` — путь к файлу базы данных SQLite
- `TODO_PASSWORD` — пароль для входа (если пустой, аутентификация отключена)

2. Запустите сервер:

```
go run .
```

3. Откройте в браузере: http://localhost:7540

## Запуск тестов

Перед запуском тестов в файле `tests/settings.go` установите:

- `FullNextDate = true` — для проверки правил повторения по неделям и месяцам
- `Search = true` — для проверки поиска
- `Token = "<токен>"` — токен, полученный из `/api/signin` при заданном `TODO_PASSWORD`

Токен можно получить так (сервер должен быть запущен):

```
curl -X POST http://localhost:7540/api/signin -d '{"password":"12345"}'
```

Запуск всех тестов:

```
go test ./tests
```

## Запуск через Docker

Сборка образа:

```
docker build -t go-scheduler .
```

Запуск контейнера:

```
docker run -d -p 7540:7540 -v $(pwd)/scheduler.db:/app/scheduler.db -e TODO_PASSWORD=12345 go-scheduler
```

- `-p 7540:7540` — проброс порта контейнера на хост
- `-v $(pwd)/scheduler.db:/app/scheduler.db` — подключение файла базы данных с хоста
- `-e TODO_PASSWORD=12345` — задание пароля

После запуска откройте http://localhost:7540
